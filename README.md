## ✨ درباره پروژه (About the Project)

پروژه **BarberShop** یک وب‌اپلیکیشن جامع و مدرن است که با الهام از برترین سالن‌های پیرایش لوکس بین‌المللی و با تمرکز بر استانداردهای طراحی ایرانی (RTL و فونت وزیرمتن) توسعه یافته است. این سامانه فرآیند نوبت‌دهی را از روش‌های سنتی و تماس تلفنی به یک تجربه دیجیتال سریع، بدون معطلی و بدون تداخل زمانی تبدیل می‌کند. همچنین بخش فروشگاه آنلاین، بستری مستقیم برای عرضه محصولات مراقبت از مو، پوست و ریش آقایان فراهم می‌سازد.

---

## 🚀 ویژگی‌های کلیدی (Key Features)

### ۱. سیستم رزرواسیون هوشمند و بدون تداخل (Smart Booking Engine)
- موتور محاسبه خودکار زمان‌های خالی و بازه‌های آزاد بر اساس مدت زمان هر خدمت
- پشتیبانی از تقویم جلالی (شمسی) و ساعت کاری آرایشگران همراه با زمان‌های استراحت (Break)
- فرم رزرو ۴ مرحله‌ای داینامیک همراه با انتخاب خدمت، استایلیست، زمان و ثبت کد رهگیری اختصاصی
- صفحه ویژه «زمان‌های خالی نزدیک» برای مشتریانی که به دنبال نزدیک‌ترین نوبت هستند

### ۲. فروشگاه آنلاین مراقبت آقایان (E-Commerce Store)
- دسته‌بندی تخصصی: محصولات مو، پوست، مراقبت از ریش، ابزار پیرایش و عطریات
- فیلتر هوشمند بر اساس دسته‌بندی، مرتب‌سازی بر اساس قیمت و پرفروش‌ترین‌ها
- سبد خرید تعاملی، اعمال کدهای تخفیف، انتخاب نشانی پستی و شبیه‌سازی درگاه بانکی شتابی (شاپرک)
- صدور و چاپ فاکتور رسمی فروش به صورت آنلاین

### ۳. پنل کاربری اختصاصی مشتریان (Customer Dashboard)
- کارت‌های شیشه‌ای وضعیت نوبت‌های فعال با افکت‌های شناور و انیمیشن‌های نرم
- ترکر وضعیت مرسولات پستی فروشگاه (ثبت، تأیید، بسته‌بندی، ارسال، تحویل)
- ویرایش اطلاعات کاربری و ذخیره ترجیحات استایلینگ (بافت مو، حساسیت به تیغ، مدل ریش)
- مدیریت دفترچه نشانی‌ها و فهرست علاقه‌مندی‌ها

### ۴. پنل مدیریت حرفه‌ای و مستقل (Custom Admin Dashboard)
- داشبورد آماری و شاخص‌های کلیدی عملکرد (KPIs) شامل درآمد امروز، نوبت‌های پیش‌رو و وضعیت انبار
- مدیریت کامل نوبت‌ها (تأیید، لغو، تغییر استایلیست)
- مدیریت خدمات و قیمت‌گذاری، محصولات و موجودی انبار
- تنظیم شیفت‌های کاری، مرخصی‌ها و ساعات استراحت آرایشگران

### ۵. تجربه کاربری و طراحی لوکس (Design & UI/UX)
- سیستم رنگی Dark Luxury با ترکیب مشکی ابریشمی (Obsidian) و طلایی متالیک (Royal Gold)
- تایپوگرافی اختصاصی زبان فارسی با فونت استاندارد Vazirmatn
- طراحی کاملاً واکنش‌گرا (Responsive) بهینه‌سازی شده برای موبایل با منوی شناور پایینی (Bottom Navigation)

## 🛠 تکنولوژی‌های استفاده شده (Tech Stack)

### بخش فرانت‌اند (Frontend)
- **React 19** & **TypeScript**
- **Vite 8** جهت بیلد پرسرعت و بهینه
- **Tailwind CSS 4** با متغیرهای طراحی و انیمیشن‌های سفارشی
- **Lucide React** برای آیکون‌های مدرن و هماهنگ
- **Persian Date & Number Utilities** برای تبدیل اعداد، مبالغ به تومان و تقویم جلالی

### بخش بک‌اند (Backend - Django)
- **Python 3.11+** & **Django 5.0**
- **Django REST Framework (DRF)** جهت طراحی RESTful API
- پشتیبانی از **PostgreSQL** و **SQLite**
- احراز هویت مبتنی بر توکن (JWT) و سیستم کنترل دسترسی نقشی (RBAC)

## 📦 راهنمای اجرای پروژه (Quick Start)

### پیش‌نیازها:
- Node.js نسخه 18 یا بالاتر
- Python نسخه 3.10 یا بالاتر (برای بخش بک‌اند)

### ۱. اجرای بخش فرانت‌اند (Frontend):
```bash
# کلون کردن ریپازیتوری
git clone https://github.com/your-username/barbershop.git
cd barbershop

# نصب پکیج‌ها
npm install

# اجرای محیط توسعه
npm run dev
```
اپلیکیشن در آدرس `http://localhost:3000` در دسترس خواهد بود.

### ۲. بیلد نسخه نهایی (Production Build):
```bash
npm run build
```

### ۳. راه‌اندازی بک‌اند جنگو (اختیاری):
```bash
cd django_backend
python -m venv venv
source venv/bin/activate  # در ویندوز: venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

## 📁 ساختار پوشه‌های پروژه (Folder Structure)

```text
├── index.html                  # مدخل اصلی HTML به همراه فونت وزیر و متا‌تگ‌های سئو
├── package.json                # وابستگی‌ها و اسکریپت‌های پروژه
├── src/
│   ├── App.tsx                 # کامپوننت ریشه و مسیریابی صفحات
│   ├── index.css               # استایل‌های سراسری Tailwind و انیمیشن‌ها
│   ├── components/             # کامپوننت‌های مشترک (Header, Footer, Nav, Toast)
│   ├── context/                # مدیریت استیت سراسری اپلیکیشن (AppContext)
│   ├── data/                   # داده‌های شبیه‌سازی‌شده واقع‌گرایانه (mockData)
│   ├── pages/                  # صفحات کامل سامانه (Home, Booking, Shop, Dashboards, ...)
│   ├── types/                  # تایپ‌های TypeScript برای رزرو، خدمات، سفارش‌ها و کاربران
│   └── utils/                  # ابزارهای تقویم جلالی، فرمت تومان و موتور زمان‌بندی
└── django_backend/             # ساختار ماژولار و مدل‌های پایگاه‌داده Django
```
